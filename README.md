# Форма

Простое Python-приложение по заданию «Предприятие — основное звено экономики». Помогает выбрать ИП, ООО, непубличное АО или ПАО по пяти параметрам бизнеса. Светлый интерфейс в стиле Liquid Glass: прозрачные поверхности, мягкие блики, стеклянные объекты и адаптивная сетка.

## Запуск

Нужен Python 3.10 или новее. Внешних зависимостей нет.

```bash
cd /home/user/Projects/EconomyProj
python3 app.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Если порт занят:

```bash
python3 app.py --port 8080
```

Остановка — `Ctrl+C`. Сервер по умолчанию доступен только с этого компьютера. Приложение полностью работает без интернета; интернет нужен только для перехода к внешним источникам.

## Использование

1. Укажите деятельность, масштаб, количество учредителей, способ финансирования и допустимую ответственность.
2. Нажмите «Подобрать форму». Справа появятся рекомендация, причины выбора, капитал и важные ограничения.
3. Раскройте преимущества и налоги, альтернативы или дальнейшие шаги.
4. При необходимости сохраните результат в `.txt` или перейдите на вкладку «Сравнение».

Кнопка примера заполняет профиль IT-студии с двумя основателями. «Сбросить» возвращает исходное состояние. При изменении параметров результат помечается устаревшим до повторного подбора; экспорт такого результата отключается.

## Почему выбраны эти критерии

| Критерий | Влияние на рекомендацию |
| --- | --- |
| Деятельность | Услуги и IT повышают приоритет простого самостоятельного старта; производство и торговля — корпоративной структуры. Это предпочтение модели, а не правовой запрет. |
| Масштаб | Малый бизнес получает приоритет простой структуры; средний — ООО; крупный повышает приоритет АО. Масштаб сам по себе не исключает формы. |
| Учредители | ИП исключается при совместном владении; ООО — при числе участников более 50. |
| Инвестиции | Частный инвестор в капитал требует долей или акций; публичное размещение акций — публичного статуса АО. Заёмные средства не считаются инвестициями в капитал в этой модели. |
| Ответственность | Если важно ограничить ответственность, ИП исключается. У ООО и АО есть законные исключения из ограничения ответственности. |

Алгоритм в `recommender.py` сначала исключает несовместимые формы, затем начисляет оставшимся баллы за соответствие критериям и выбирает максимум. При равных баллах порядок: ИП → ООО → АО → ПАО. Баллы — учебная эвристика, не вероятность успеха и не юридическая оценка. Для каждого добавления баллов сохраняется текст причины. Все формы, кроме рекомендованной, показываются как альтернативы с пояснениями.

Не рассматриваются специальные формы, например производственные кооперативы, товарищества и КФХ. НПД не представлен как ОПФ, поскольку это налоговый режим. Не рассчитываются налоги, лицензии, ограничения по иностранному участию или специальные требования отрасли. Минимальный капитал указан для общего случая. Базовые правовые сведения проверены 11.11.2026; перед реальной регистрацией следует проверить действующие нормы и обратиться к специалисту.

## Устройство

- `app.py` — HTTP-сервер стандартной библиотеки Python, статические файлы и API.
- `recommender.py` — проверка входных данных, правила, тексты рекомендаций.
- `static/` — HTML, CSS, JavaScript без библиотек и внешних ресурсов.
- `tests/test_app.py` — проверки правил и HTTP API.

Данные формы отправляются только локальному Python-серверу. Нет базы данных, аналитики, cookies и localStorage. Сервер не сохраняет тела запросов. В журналах стандартного HTTP-сервера остаются URL и статусы запросов.

## Проверки

```bash
python3 -m unittest discover -s tests -v
```

Проверяются типовые сценарии, границы 50/51 участник, неверные входные данные, 450 сочетаний критериев, загрузка ресурсов и API. Интерфейс поддерживает клавиатуру, системное уменьшение анимации и узкие экраны.

Сервер стандартной библиотеки предназначен для локального учебного запуска. Для публичного размещения потребуется отдельная настройка промышленного сервера.
